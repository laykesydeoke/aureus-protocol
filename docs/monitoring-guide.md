# Monitoring Guide

## Key Metrics to Track

1. **TVL**: Total Value Locked (target: growing)
2. **Avg Yield**: Average yield bps (target: > 500 bps)
3. **Protocol Uptime**: Blocks since last pause
4. **Pause Count**: Historical pause events

## Alerting Thresholds

- TVL drops > 10% in 100 blocks: Investigate
- Pause count increase: Immediate review
- Avg yield drops below 100 bps: Rebalance check
