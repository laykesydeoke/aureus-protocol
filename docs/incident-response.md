# Incident Response Guide

## Detection

Monitor for:
- Unusual TVL changes
- Failed transaction spikes
- Oracle price deviations

## Response

1. **Immediate**: Emergency pause
2. **Assess**: Review on-chain data
3. **Remediate**: Deploy patches
4. **Restore**: Resume operations
5. **Report**: Post-incident analysis

## Contacts

- Contract owner holds emergency pause capability
- Community multisig for governance decisions
